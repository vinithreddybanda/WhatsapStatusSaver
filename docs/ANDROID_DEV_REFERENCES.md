# Android development references

These open-source projects and official resources informed the gallery and testing work.

- [Android Skills](https://github.com/android/skills): Google's agent-oriented Android implementation guidance and workflows.
- [PinterestStyleGridDemo](https://github.com/vsay01/PinterestStyleGridDemo): variable-height Compose staggered grid, progressive loading and placeholders.
- [ImageGalleryApp](https://github.com/burhan-zummar/ImageGalleryApp): local-media pagination, repository separation and Coil image loading.
- [mcp-mobile-interaction](https://github.com/pablonortiz/mcp-mobile-interaction): Claude Code MCP for Android screenshots, UI trees, gestures, logs and recordings.

Official platform guidance:
- [Compose lazy lists and staggered grids](https://developer.android.com/develop/ui/compose/lists)
- [Lazily load lists with Paging](https://developer.android.com/develop/ui/compose/quick-guides/content/lazily-load-list)
- [Optimize bitmap loading](https://developer.android.com/develop/ui/compose/graphics/images/optimization)
- [Immersive mode and system bars](https://developer.android.com/develop/ui/views/layout/immersive)
- [Android storage updates](https://developer.android.com/about/versions/11/privacy/storage)

The app uses its existing local filesystem repository and Coil setup. The references are patterns, not copied app implementations or additional runtime dependencies.
